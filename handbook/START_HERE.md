# CityAtlas Handbook - Start Here

CityAtlas is being built as a Vancouver-first public discovery product with a business-growth layer behind it.

This package is not yet a live company site. It is a launch-ready pre-domain product package designed so the owner can review the product, business model, safety gates, and next steps before purchasing a domain or accepting payments.
