# Real-World Source Policy

## Purpose

CityAtlas can become powerful only if real-world information is handled conservatively. This policy defines the minimum source and review rules before real businesses, events, offers, or missions become public.

## Source Hierarchy

Preferred sources:

1. Direct business approval or submission.
2. Official business or venue website.
3. Official booking, ticketing, or menu page linked from the business.
4. Official public organization page for markets, galleries, venues, or attractions.
5. Reputable editorial or guide source for context only, never as the only source for operational facts.

Do not rely on:

- scraped directory snippets as primary truth
- stale third-party hours
- unsourced AI summaries
- social captions without confirmation
- user reviews for factual claims

## Required Fields Before Public Listing

- name
- category
- neighborhood or address
- official website or approved source
- source date
- source owner
- review status
- correction/removal path
- claim limitations

## Claims Rules

Allowed after source review:

- neutral descriptions
- location
- categories
- booking or menu links
- source-backed hours or event dates
- owner-approved offer terms

Needs extra review:

- awards
- rankings
- "best" claims
- ratings
- health, wellness, finance, legal, or safety language
- alcohol-related claims
- pricing claims
- accessibility details

Never publish without approval:

- private contact data
- scraped images
- copied menu text beyond brief factual references
- invented ratings
- invented review counts
- guaranteed traffic, bookings, or revenue

## Mission Rules

A real City Mission needs:

- all included places verified
- route promise reviewed
- current hours checked close to publish date
- accessibility and age restrictions checked when relevant
- no implied sponsorship unless approved
- no "open now" claim without live data

## Business Correction Path

Every real page should include or route to:

- claim this page
- request correction
- request removal
- report outdated info

## Private Preview Rules

Private previews may use real candidate names only when:

- the source links are saved
- the page is clearly marked private/review draft
- the preview route itself remains blocked from search and public navigation
- no payment is requested
- no endorsement is implied

## Launch Gate

Real-world content is blocked until the owner approves:

- source policy
- first source list
- public claim rules
- correction/removal process
- privacy/terms posture
