# CityAtlas Content Quality Gate

This folder is the trust gate for CityAtlas editorial work.

Use it after the opening angle is chosen. A piece should only move forward when it is useful, specific, honest, and clearly tied to a CityAtlas next step.

## Primary Rule

More pages are not the win. More trusted, answer-first Vancouver planning help is the win.

## Read Order

1. `RELEASE_CHECKLIST.md`
2. `../hook-intelligence/HOOK_RUBRIC.md`
3. `../seo-aeo-geo/SOURCE_BACKED_WEDGE_TEMPLATE.md`

## Default Decisions

- `Ship` only when the page is locally useful and claim-safe
- `Revise` when the angle is right but the draft is still generic or under-supported
- `Kill` when the page would attract the wrong audience or create trust debt
- `Rebuild` when the underlying query or structure is weak

## Extra Rule For Real-Place Pages

If a page names real Vancouver venues, the page is not ready unless it shows:

- official public sources
- checked date
- clear claim boundaries
- correction path at `/editorial-standards`

## Why This Matters

CityAtlas is still partly demo-first. That means every useful public-safe page has to be narrower and more honest than a normal city blog. This gate protects that discipline.
