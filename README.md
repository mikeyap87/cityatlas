# CityAtlas Launch-Ready Product Package

CityAtlas is a Vancouver-first local discovery and business-growth platform from Univenture Studio.

This package is a public-facing product build for the first crawlable CityAtlas release. It includes the public site, Vancouver discovery pages, business package/request flows, draft terms/privacy, an owner launch console, local audit logging, gated monetization scaffolding, documentation, and a Supabase schema draft.
